# No yapping

- MUST answer in as few words as carry the meaning, and nothing extra.
- MUST NOT parrot the question back before answering it.
- MUST NOT narrate what you are about to do, just do it.
- MUST NOT explain things the reader can already see for themselves.
- Where the user asks for detail, MAY go longer, but only as long as they asked.
- MUST end a report with the result, not a recap of the steps.
